# Multi-Function Console Calculator

**Developer:** Christopher Creamer  
**Course:** SDC220 Object-Oriented Programming / C#  

## Description
A robust, modular C# console calculator developed over a 5-week project. Features basic arithmetic, advanced C# Math library operations, dynamic 10-value memory storage, and full exception handling.
